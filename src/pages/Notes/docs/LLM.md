## NLP 任务

- 中文分词：是标注词性等后续工作的基础
- 子词切分：借助基础词汇的组合，分析未知的新的复杂词汇

## 词表示

- One-hot：人工排布，过于稀疏，也不能表示位置信息
- N-gram：上下文大小受限，N 过大后训练很难收敛
- word embedding：生成密集向量，可以自动提取词汇相对关系
- ELMo：双向LSTM，提取的信息有限，而且训练效率低

# 第二章 Transformer 架构

## 过往网络结构

- MLP：多层全连接，权重直接等于信息，参数量大，信息密度不高
- CNN：通过卷积核逐步提取和压缩局部信息，上下文太局限
- RNN：通过自循环增加了时序演进机制，所以无法并行计算
- LSTM：只是在 RNN 基础上缓解了信息衰减问题

## 注意力机制

### 基础版本

实质上是计算多个 K 对应的 V 的加权合并的结果，权重比例是 Q 和全量 K 分别的相似度。

> $$ attention (Q,K,V) = softmax (\frac{QK^T}{\sqrt{d_k}})V $$

- $Q$：全量 query
- $K^T$：要查询的 key 矩阵，因为计算点积相似度而转置
- $d_k$：排除 batch size 和 attention head 后的向量的长度，一般是 Q.shape[1]
- $softmax$：因为目的是按比例组合不同的 value，所以需要归一化
- $V$：即是要查询的 value 矩阵

### 工程变种

- 自注意力：
    - Q、K、V 分别为同一序列经过对应 $W_q$、$W_k$、$W_v$ 变换后的结果
    - 使用 Q、K 两个不同的矩阵来变换，而不是单个矩阵，计算过程是非线性的，二次幂的，可以表达更复杂的信息
- 掩码注意力：
    - 每个 token 只能使用当前位置以前的 token 计算 Q、K、V
- 交叉注意力：
    - 每个 token 可以使用整个序列里所有 token 计算 Q、K、V
- 多头注意力：
    - 并列的多套注意力参数，工程上实现为矩阵的拼接

## transformer 网络结构

> 其他资料：
> - [王木头 一步一步理解 Transformer、Attention](https://www.bilibili.com/video/BV1XH4y1T76e/)

### 核心组件

- embedding：token id 对应的向量表示，可学习
- 位置编码
    - 因为矩阵在行上的交换性质，embedding 堆叠的顺序并不能体现 token 的顺序
    - 根据把 embedding 向量位置直接反映在数值上，通过这种方式来携带位置信息
- layer-norm
    - 和其他神经网络一样，每一层的计算之后，需要 normalize 重新均衡数值分布
    - 用 pre-norm 比用 post-norm 时 loss 更稳定，每一层的梯度可以直接传播到 tensor，梯度没有经过 norm
- Encoder
    - 通过多层 transformer 把输入序列编码为隐藏状态
- Decoder
    - 从隐藏状态中递归提取 token 的分布概率，经过后续 token 选择

### 位置编码

##### 绝对位置编码

绝对位置编码有固定的计算方式，直接根据词向量下标来修改词向量数值内容。
原版的位置编码就是一种绝对位置编码，公式为
$$PE (pos,2i)=sin (\frac{pos}{10000^{\frac{2i}{d_{model}}}})$$
$$PE (pos,2i+1)=cos (\frac{pos}{10000 ^{\frac{2i}{d_{model}}} })$$
这个公式计算出的偏移值，随着$i$增大逐渐变小，而且相邻值的差值也越来越小，由于是负指数函数，所以支持很大的 $i$，

##### 相对位置编码

比起绝对位置编码的固定偏移量，相对位置编码通过两个词向量之间的相对距离来描述位置关系

- **Shaw et al. (2018)**：将相对距离截断在 $[-k, k]$，为 Key/Value 学习相对位置向量 $a_{ij}^K$ $a_{ij}^V$
- **Transformer-XL**：用正余弦相对位置矩阵 $R_{i-j}$ 和可学习偏置 $u$、$v$ 替换绝对位置点积
- **T5 Bias**：将相对距离分桶后查表得到偏置 $B$，直接加到注意力分数上
- **ALiBi**：无参数，在注意力分数上减去线性距离惩罚 $-m \cdot |i - j|$
- **RoPE（旋转位置编码）**：对 $Q$、$K$ 做二维分组旋转，使内积天然只依赖相对距离 $n - m$
