# Cyan's fun

## Setup

Install the dependencies:

```bash
pnpm install
```

## Get Started

Start the dev server:

```bash
pnpm dev
```

Build the app for production:

```bash
pnpm build
```

Preview the production build locally:

```bash
pnpm preview
```

## 内容目录

- `src/pages/Notes/docs`：学习笔记，包含 NLP / Transformer 与 CUDA。
- `src/index.tsx`：Rsbuild 应用入口与路由配置。
- `src/pages/`：React 页面实现。
- `public/`：站点图标、游戏音效等静态资源。
