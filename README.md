# Cyan's fun

## Setup

Install the dependencies:

```bash
pnpm install
```

## Get Started

Start the dev server:

```bash
pnpm dev
```

Build the app for production:

```bash
pnpm build
```

Preview the production build locally:

```bash
pnpm preview
```

生产文件输出到 `doc_build/`。类型检查使用 `pnpm typecheck`。

## 内容目录

- `docs/happy-llm/`：学习笔记，包含 NLP / Transformer 与 CUDA。
- `docs/games/`、`docs/sticky.tsx`：原页面路径的 Rspress 路由入口。
- `src/pages/`：保留的 React 页面实现。
- `docs/public/`：站点图标、游戏音效与文档许可证。
